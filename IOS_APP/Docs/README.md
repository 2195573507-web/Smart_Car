# SmartCarApp Local Notes

The authoritative iOS architecture, audit, and development records are kept
in the workspace-level `DOCS/` directory so they remain indexed with the
system, S3, STM32, and ROS2 documentation.

This directory is reserved for app-local artifacts such as future Xcode setup
notes, simulator procedures, and generated-interface guidance. It contains no
BLE UUID, vehicle-control, or hardware configuration contract.
