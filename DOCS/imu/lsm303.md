# LSM303 Module

## Function

Read LSM303-compatible accelerometer and magnetometer data over I2C4 and
convert raw registers into engineering units.

## Source Location

`STM32H757/Drivers/IMU/LSM303/lsm303.c/.h`.

## Entry Functions

`lsm303_init`, `lsm303_init_diag`, `lsm303_get_accel_id`,
`lsm303_get_mag_id`, `lsm303_read_acc`, `lsm303_read_mag`,
`lsm303_is_ready`.

## Inputs

I2C4 PD12/PD13, default 7-bit addresses `0x19` accel and `0x1E` mag, device
identity registers and measurement registers.

## Outputs

`Vector3f` acceleration in m/s2, magnetic vector in microtesla, IDs, readiness,
and BSP status codes.

## Body-Frame Mapping

`imu_manager.c` applies one proper rotation at acquisition:

```text
R_lsm_body = diag(-1, -1, +1)
R_lsm_body^T R_lsm_body = I
det(R_lsm_body) = +1
```

This is a 180-degree rotation about Body Z, not an independent axis mirror.
Static calibration, Leveling, legacy attitude, and DualAHRS consume the
resulting Body Frame representation. BMI323 uses its existing axis definition
and is not transformed by this mapping.

## Public Interfaces

`lsm303_init`, `lsm303_init_diag`, identity getters, accel/mag reads, and
`lsm303_is_ready`.

## Dependencies

`bsp_i2c`, `bsp_status`, timer/log diagnostics, IMU manager.

## Current Status

Active primary IMU source path. Current code and docs do not constitute an I2C
electrical or board acceptance result.

## Known Issues

Magnetometer axis ordering and sample pairing must remain explicit. A separate
accel/mag read can have different success ticks.

## Modification Notes

Keep address probing, unit conversion, failure status, and complete-sample
publication behavior compatible. Do not switch the primary sensor casually.
