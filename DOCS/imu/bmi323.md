# BMI323 Module

## Function

Provide an SPI1 BMI323 accelerometer/gyro/temperature driver and diagnostics.

## Source Location

`STM32H757/Drivers/IMU/BMI323/bmi323.c/.h`.

## Entry Functions

`bmi323_init`, `bmi323_init_diag`, `bmi323_get_chip_id`,
`bmi323_read_acc`, `bmi323_read_gyro`, `bmi323_read_temperature`,
`bmi323_is_ready`.

## Inputs

SPI1 PA5/PA6/PA7, software CS PC4, expected chip ID `0x0043`, and reset/config
transactions.

## Outputs

Engineering-unit vectors, temperature, chip ID, readiness, and diagnostic
status/logs.

## Public Interfaces

`bmi323_init`, `bmi323_init_diag`, sensor reads, chip-ID getter, and
`bmi323_is_ready`.

## Dependencies

`bsp_spi`, `bsp_gpio`, HAL delays/status, IMU manager.

## Current Status

Driver retained; runtime path paused. Current IMU startup explicitly logs
`BMI323 SKIPPED` and uses LSM303.

## Known Issues

Historical diagnostics reported startup/CHIP_ID failure boundaries, but no live
bus trace is part of this documentation task.

## Modification Notes

Do not reactivate BMI323 by masking LSM303 or changing shared transport. Require
an explicit hardware/software decision and reset-to-runtime evidence first.
