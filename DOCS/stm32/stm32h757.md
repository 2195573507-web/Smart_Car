# STM32H757 Module

## Function

Own deterministic vehicle-side sensing, calibration, filtering, attitude,
local communication service, logging, RTOS scheduling, and final motion/safety
authority.

## Source Location

`STM32H757/CM7/`, `BSP/`, `Drivers/`, `Middleware/`, `Application/`, and
`System/`.

## Entry File

`STM32H757/CM7/Core/Src/main.c::main` initializes cache/HAL, boot logging,
GPIO, USART1 logging, the USART2 transport link, I2C4/TIM1/TIM2/TIM3, IMU
runtime, UART/S3 tasks, and the scheduler.

## Inputs

LSM303 I2C samples, BMI323 SPI diagnostics when enabled, STM-S3 UART frames,
timer/RTOS events, motor/encoder signals, and local safety conditions.

## Outputs

Filtered/attitude state, boot/log events, STM-S3 source frames, and future
motor/encoder control behavior under local safety policy.

## Public Interfaces

`imu_*`, `uart_link_*`, `s3_service_*`, shared `scbp_*`, BSP UART/I2C/SPI/PWM,
calibration/filter/attitude interfaces, and RTOS health interfaces.

## Dependencies

Generated CM7 HAL/Core, FreeRTOS, board BSP, sensor drivers, middleware,
communication services, and frozen hardware allocations.

## Current Status

The source tree contains active boot, USART1 logging, manual USART2 transport,
LSM303 pipeline, calibration/filter/attitude, and service task code. Motor and
encoder driver public APIs are placeholders; live hardware acceptance is not
established by this documentation task.

## Known Issues

- Legacy IOC PD3/PD4 connector labels conflict with current generated USART2
  PA2/PA3 MSP/source usage.
- BMI323 is retained but paused; LSM303 is active.
- RF/RB encoder pairs are statically allocated; LF/LB frozen nets do not support
  timer encoder mode.

## Modification Notes

Respect generated HAL/IOC boundaries and local safety authority. Before any
change inspect the affected task, stack/context, ISR/DMA relationship, public
header, and S3/App consumer. A CM7 build is not physical or vehicle evidence.
