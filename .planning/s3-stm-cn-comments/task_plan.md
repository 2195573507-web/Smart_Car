# S3 与 STM 中文注释完善计划

## 目标

在不改变现有运行行为、协议、接口和硬件资源归属的前提下，为项目自有的 S3、STM32 与共享 SRP 代码补充准确、可维护的中文注释，并将纯调试配置集中到公共头文件。

## 范围与约束

- 只修改项目自有源码、头文件和本任务文档。
- 不修改 CubeMX 生成代码、HAL、CMSIS、FreeRTOS、ESP-IDF 第三方源码。
- 保持 SRP v4、UART/GPIO 归属、`[RR, RF, LR, LF]` 顺序、控制安全门和已有接口不变。
- 注释必须由当前实现、调用点或构建配置证明；硬件运行状态不得由构建结果推断。
- 工作树中的 iOS、IMU、DualAHRS、控制行为等并发修改不归属于本任务，不回退、不改写。
- CM7 只使用规范构建目录 `STM32H757/CM7/build/Debug`。

## 已知风险

| 风险 | 控制方式 |
|---|---|
| 注释与实现不一致 | 同时阅读声明、定义和调用点，逐项核对阻塞、线程、中断、所有权和单位 |
| 宏迁移改变行为 | 只迁移纯诊断配置并保持默认值；影响解析、容量或控制语义的常量留在模块内 |
| 并发修改被误归属 | 以路径和 diff hunk 为单位核对，不回退未知修改 |
| 构建被误报为硬件通过 | 仅报告源码/主机/构建证据，UART、BLE、传感器和车辆运行继续标为未验证 |
