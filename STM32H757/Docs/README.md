# STM32H757 Engineering Notes

This directory contains the STM32H757 architecture, module status, S3
communication boundary, BSP interfaces, driver guidance, development log, and
independent audit. CubeMX generation remains under the existing
`cubemx_generate.script`; generated sources and HAL files are not maintained
here.

The BSP contract is defined in `HARDWARE/BSP_INTERFACE.md`; driver usage and
resource limitations are defined in `DRIVER/BSP_DRIVER_GUIDE.md`.
